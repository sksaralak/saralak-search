# Saralak Search — Public Content Writing Rules

Use this file when writing, revising, or QA-ing public-facing content on saralak-search.com.

## 1. Public copy must read like an expert article, not an internal SEO report

Do not expose internal research or planning notes in reader-facing copy.

Avoid phrases such as:

- จาก SERP ไทยที่ตรวจวันที่...
- Ahrefs Snapshot วันที่...
- Search Intent หลักคือ...
- Owner URL คือ...
- Commercial relevance...
- จากการ audit พบว่า...
- ในเอกสารปี 2026...
- SERP แสดงว่า...
- Keyword Difficulty เท่ากับ...
- Parent Topic คือ...

These can be used internally for planning, but should normally be removed from the live article.

Rewrite them into useful reader-facing language.

Bad:
> จาก SERP ไทยของคำ “geo คือ” ที่ตรวจวันที่ 5 ตุลาคม 2026...

Better:
> GEO มักถูกพูดถึงคู่กับ SEO เพราะทั้งสองแนวทางเกี่ยวข้องกับการทำให้ข้อมูลถูกค้นพบ แต่ GEO ขยายไปถึง AI Search และ Generative AI

## 2. When citing Google or another primary source, use natural source language + inline link

Do not write like a research memo:

Bad:
> ในเอกสารปี 2026 Google ระบุว่า...

Preferred:

> จากข้อมูลของ Google...
> Google ระบุว่า...
> ข้อมูลจาก Google Search Central ระบุว่า...

Link the source directly on the natural source phrase, for example:

> จาก [ข้อมูลของ Google Search Central](SOURCE_URL) ...

or

> [Google ระบุว่า](SOURCE_URL) ...

The surrounding sentence must still sound natural if the link is removed.

## 3. Do not surface research-tool metadata unless the number itself helps the reader

Ahrefs, Search Console, SERP observations, keyword volume, KD, Parent Topic, or trend data may be used when they add real information.

Do not show them merely to prove that keyword research was done.

If a number is useful:
- explain what decision it supports
- give context
- state that it can change when relevant
- avoid turning the article into a keyword report

## 4. Main keyword should appear naturally in important headings

Use the page's main keyword in:
- H1
- selected important H2s
- selected H3s when natural

Do not force the exact phrase into every heading.

The goal is clear topic ownership, not keyword stuffing.

Example for main keyword "GEO คืออะไร":

Good H2s:
- GEO คืออะไร
- GEO คืออะไร ต่างจาก SEO อย่างไร
- GEO คืออะไร และทำไมถึงสำคัญกับธุรกิจ
- สรุป GEO คืออะไร

Avoid repeating "GEO คืออะไร" in every H2 if it makes the page sound unnatural.

## 5. Internal links should follow topic ownership

When a relevant Saralak Search owner page exists, use a descriptive or exact-match anchor naturally.

Examples:
- SEO คืออะไร → /blog/what-is-seo
- AEO คืออะไร → /blog/what-is-aeo
- GEO คืออะไร → /blog/what-is-geo
- AI Overview คืออะไร → /blog/what-is-ai-overview
- วิธีทำ GEO → /blog/how-to-do-geo
- GEO Checklist → /blog/geo-checklist-thailand
- llms.txt คืออะไร → /blog/llms-txt-thailand
- ทำ GEO ที่ไหนดี → /blog/geo-agency-thailand

Do not link the same primary keyword to multiple competing URLs.

## 6. Depth rule

Do not keep an important H2 as a short placeholder.

A major section should normally contain:
- a direct answer
- enough context to stand alone
- an example, comparison, decision rule, evidence, or limitation when useful
- a contextual internal link when a deeper owner page exists

Do not add words only to make the article longer.

## 7. Tone

Public content must sound:
- human
- specific
- consultant-written
- clear
- useful
- confident without overclaiming

Avoid language that sounds generated or like an audit template.

Avoid:
- ในยุคดิจิทัล
- ปฏิเสธไม่ได้ว่า
- มีความสำคัญอย่างยิ่ง
- กล่าวโดยสรุป
- จาก SERP ที่ตรวจ...
- จาก Ahrefs Snapshot...
- Owner URL
- Commercial relevance

Use concrete statements instead.

## 8. Source vs methodology

Keep official information separate from Saralak Search methodology.

For official claims:
- cite and link the primary source inline
- use wording such as "Google ระบุว่า..." or "จากข้อมูลของ Google..."

For Saralak Search methods:
- say "Saralak Search ใช้..." or "จากการทำงานจริง เราใช้..."
- never present an internal framework as a Google ranking factor

## Final QA

Before publishing, check:

- [ ] No internal SEO research notes appear in public copy
- [ ] Source references sound natural and link to the primary source
- [ ] Main keyword is distributed naturally across H1/H2/H3
- [ ] Important H2s have enough depth
- [ ] Internal links use the correct owner URL
- [ ] Exact anchors are used where natural
- [ ] No keyword stuffing
- [ ] No unsupported Google / AI claims
- [ ] Copy sounds like an expert article, not an AI report
