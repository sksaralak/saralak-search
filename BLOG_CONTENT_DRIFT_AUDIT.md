# Blog Content Drift Audit

Audit date: 2026-10-08
Scope: all 27 requested production article routes compared with the repository SSR render.
Deployment status: **BLOCKED — reconciliation is complete in the working tree and awaits review.**

## Method

- Used the original drift audit as the reconciliation checklist.
- Ported the current production-authored article content and metadata from `origin/main` into the repository while retaining `BlogProse`, the shared blog components, and central blog CSS.
- Rendered every repository article route through an isolated SSR build.
- Fetched the matching production page and compared H1, title, meta description, canonical URL, published/modified dates, FAQ schema, article text blocks, links (destination and visible label), and images.
- Normalized presentation-only differences caused by shared components, including generated TOC/step numbers and decorative arrow glyphs.
- No production or deployment state was changed.

## Review items and intentional equivalences

No unresolved or ambiguous editorial text differences remain. Reviewers should still acknowledge these intentional implementation differences before deployment:

1. TOC and step numbering is generated by shared semantic components rather than stored as manually typed list numbers. Rendered wording is equivalent and duplicated numbering is avoided.
2. Related-link arrows are decorative shared-component glyphs rather than the production SVG implementation. Link labels and destinations match.
3. The `/blog/what-is-seo` ecommerce proof uses `/images/blog/what-is-seo/seo-case-ecommerce-organic-result.png`, the previously requested working replacement for production's `/image/blog/what-is-seo/seo-nonbrand-packaging-serp.webp`. The comparator treats these as the approved equivalent asset reference.
4. Element wrappers and CSS classes intentionally differ where `BlogProse`, `ResponsiveTable`, `TableOfContents`, `FAQSection`, `CTABox`, and other shared components replace one-off article markup. Article meaning and SEO structure are preserved.
